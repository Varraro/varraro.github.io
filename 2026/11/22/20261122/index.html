周刊 -

事件

  1. 全市场大毁减，也是意料之中了，regime 变的时候说白了说明加息预期改变了市场模式，之后再怎么反弹估计到下个月落地了还要再爆爆爆
  2. 上次说没法整港股然后就发现了大门支持全市场了，绷，转去玩玩，希望支持碎股，但我的评价是就那流动性也不知道碎股能不能成交（）

信息

  1. 依旧在如今的 regime 变了的时局下找策略，emmmm 总之老策略还是给出了华胜天成 看来 beta还是给出了我想要的结果，进去这不是轻轻松松 5% 然而我自己主观了一下别的股美美没了 300 米，气晕（），今后宁可按照旧策略也不主观了
  2. 本周依旧 Astra 无限美美爽用了一周，搞了一堆有意思的玩意儿，而且还顺手用 poke 白嫖了 devin，赛博鸡蛋好耶！这下 A➗的 Claude 也莫名奇妙有了 100 刀，上来拿来润了一下文字 aigc 率直接成 0了，我趣这就是最文艺的模型的神力嘛。感觉堪比1 个月前爽用大肥鱼的时光
  3. 6.2Astra 还是比 6Astra 感觉弱一点，不知道为什么也不问我问题了也不发散一点思考了整个就是个 sol 的味道了关键是还没 sol 快
  4. 疯狂探索后龙虾时代的产品，Muse 上面也是按照推上面的整了个羊毛模块，整体还算能用。Grokbot 整了一下本地的有点失望，感觉并不是像我想的那样好用。Hermes 倒是挺好用的，这个希腊克莱因蓝风格的网页还真是值得学习一下了，icon 还是 nous girl，于是反手就把这玩意儿变成了找 alpha 的全天候终端（说起来这玩意儿聪明的地方是我可以让它去有困难问 gemini 啊反正都算是 agent 同事了互相串个门什么的 x）
  5. 至于手机上兜兜转转 dshgo mika 等等诸如此类最后还是放弃了，主要原因是又烧 tokens 又慢，看着简直是急晕了

灵感

  1. 早些时候就得到过一个项目本质比特币期权现货收敛吃贴水，之前想办法变成 im 的但是也没试，最早其实还试过做 nvda 和港股的，但是最后都无疾而终了。知道现在发现 gate 这玩意儿以后想想也许能回炉重造一下呢，虽然资金要求的确很多但是我可以模拟盘啊（）
  2. 手机上看到个虚拟机项目算是把豆包手机的系统都给 down 了，不得不感叹 ai 时代这种玩意儿也是越来越多了，说不定以后整个外置大脑完全可以实现吧。应该会试试酷安人有人分享自己整的复刻豆包手机助手的项目，当然了eta 这种就算了，目前的不要 root 的手机 agent 跟个玩具似的甚至 mika 这种连 shell 都没有太唐了
  3. 终于可以验一下港股的量化到底怎么样了，虽然到目前为止全是我手动开单，不过我的评价是就我那几千说不定也卖不进去

系统

  1. 重做了一个自行探索alpha的Agent，检验需要时间
  2. 把某应用打包成了agent，还行吧比原来那坨好用

碎碎念

  1. 这周感情 shock 有点多（） 先是周二半夜老登 10 点多催论文，狠狠挨了一顿骂最后把论文投出去了，老实说我的确没写过中文论文不懂里面格式要求这么多写的确实依托，但说实在的老登最开始说的只发一篇论文就毕业他也是个大骗子 不过反正现在投都投了也无所谓了，毕竟我组的气氛温度感觉也是逐渐不能成为温馨家园了，或者说，感受一下真正的强度吧！说起来那天晚上被骂了还挺烦的，现在无所谓了反正干工作本质没心没肺就完事了（）
  2. 然后是经典我的不好的理工做题区嫉妒 ego 发作了。虽然我一直以来想把自己登味的做题区 ego 给收起来但是实际上也怪难的（）不过我也是随便写写东西罢了，毕竟咱对于感情这方面的确是个笨蛋，所有的东西只能靠揣测（），虽然不知道敏感是对我讲的嘛（应该就是了吧 x）我还是道歉比较好一点毕竟我应该是还在暗恋？！…吧 这就是我自己最喜欢自己的特质也就是经常 feedback ，原来我本质上也是个具备自进化能力的 Agent RL 嘛（）
  3. 经常有动笔画画的想法不知道为什么时间就是不够用，甚至现在发现连微信读书和漫画都很少看（最爱的历史小说和漫画都在吃灰啊！），每天起来就是中午晚上却又睡不着，整了瓶可乐桶当晚安酒但是感觉还是牛奶比较好一点，能给人一种安心的感觉。
  4. 说起来即便是在遭遇 shock 的情况下锻炼（甚至是三开有氧拳击 风骚律师和崩铁）依然有条不紊，甚至去城里恰了烤鸭自助好耶！
  5. 下周就试试港股的水到底深不深了，感觉会比较深，说实在的朋友建议我从基金（场内 场外）入手的确是有点道理的，但是回测一下 只能做到 8% 场外年化，说起来大资金这么玩没啥问题，y1s1 现在应该是我全人生试错成本最低的时候可以乱搞（），正经人早就 voo 和定投工商银行了谁整这些幺蛾子（）
  6. 总之是非常神奇的一周，虽然每周的结尾总以无聊的组会结束，呃呃（一个幽灵，一个名为组会的幽灵）
